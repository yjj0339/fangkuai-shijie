# 我的世界 · 网页版

**在线游玩：<https://yjj0339.github.io/fangkuai-shijie/>**（手机浏览器也能玩）

一个致敬 Mojang《Minecraft》的纯前端体素沙盒游戏：无限世界、完整生存要素、全程序化生成（纹理/地形/音效均为运行时生成，零素材文件、零构建步骤）。

## 玩法速览

| 操作 | 功能 |
|---|---|
| W A S D / 空格 | 移动 / 跳跃（双击 W 冲刺，水中上浮） |
| 鼠标左键（按住） | 挖掘方块（不同方块不同硬度，带裂缝进度） |
| 鼠标右键 | 放置方块 / 吃食物 / **点燃 TNT** |
| 滚轮 / 1-9 / 中键 | 切换快捷栏 / 选取方块 |
| E | 背包（27 格）· 创造模式为全物品栏 |
| Shift / 双击空格 | 潜行防坠 / 飞行（创造） |
| T 或 / | 聊天命令：`/time set day` `/gamemode c` `/tp x y z` |
| F3 | 调试信息（FPS/坐标/群系/种子） |
| Esc | 暂停菜单（切换生存/创造、重置世界） |

手机端：左下虚拟摇杆移动、右侧滑动转视角、点按放置、长按挖掘。

## 特性

- **无限世界**：区块流式加载，海洋/海滩/平原/森林/沙漠/雪原/山地 7 种群系
- **地形生成**：Simplex 多层噪声山地、地下洞穴、煤/铁/金/钻石矿脉、基岩层
- **植被**：橡树/白桦/云杉/仙人掌/草丛/蒲公英/虞美人
- **完整物理**：重力、跳跃、碰撞、游泳潜水（氧气泡）、摔落伤害、潜行防坠
- **昼夜循环**：10 分钟全天，太阳月亮星星、晨昏霞光、方块光影（平滑 AO + 天光）
- **生物**：猪/牛/羊（可猎取食物与羊毛）、夜晚刷僵尸（白天燃烧）
- **掉落物**：小方块旋转漂浮、磁吸拾取
- **TNT**：右键点燃 → 闪烁 → 球形爆炸破坏地形 + 连锁引爆
- **生存系统**：红心生命、氧气、食物回血（猪排/牛排）、死亡重生
- **存档**：自动保存到浏览器（种子 + 改动 + 背包 + 时间）
- **音效**：WebAudio 实时合成（挖掘/脚步/爆炸/受伤……按材质变调）

## 本地运行

直接双击 `index.html`，或：

```bash
node tools/server.js 5173   # 打印局域网地址，手机可连同一 Wi-Fi 预览
```

## 技术

Three.js（vendor 内置）+ ES Modules，无构建。方块网格按区块合批（面剔除 + 方向光照 + 顶点 AO + 列式天光烘焙进顶点色），16×16 像素纹理与等距物品图标由 Canvas 程序化绘制，音效由 WebAudio 合成——整个游戏没有任何二进制素材。

`tools/smoke.js` 为无头浏览器冒烟测试（自动开局/挖掘/TNT/截图）。
